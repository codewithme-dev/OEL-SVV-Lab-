# Smart Railway Crossing Control System (SRCCS) - V&V Lab

## Project Structure
- `requirements/`: Contains refined requirement analysis and identified defects from the original informal requirement.
- `z-spec/`: Contains state-based modeling using Z specification concepts (CZT format).
- `vdm/`: Contains the functional specification written in VDM++.
- `alloy/`: Contains the relational safety model using Alloy.
- `logs/`: Contains formal verification logging, traceability explanation.
- `screenshots/`: Contains output and git history screenshots as required.

## Tools Required
- Community Z Tool (CZT)
- Overture IDE
- Alloy Analyzer

## Student Submission
- **Requirement Analysis**: Validated precision and verification attributes. 
- **Formal Verification**: Z invariant maintained, VDM pre/post conditions executed, and Alloy analyzer generated bounds confirming 0 safety violations.
